# GLAMSTAR

London, January 1982. You have a voice, three mates from the pub and a band name scribbled on a beer mat. Build the band, survive the circuit, sign the deal that rips you off, and try to still be standing when the decade ends.

A rock-career management sim inspired by *Rockstar* (1989), with real characters, hidden traits and band chemistry at its core.

## Run it

```bash
npm install
npm run dev
```
